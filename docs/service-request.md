# คำขอบริการภายใน (Service Request)

พนักงานทีมอื่นใน @sinostech.co.th ขอให้ทีมช่วยทำงานภายใน เช่น ข้อมูล รายงาน ตั้งค่า เลขคำขอ `SR-<ปี>-<เดือน>-<เลขรัน>` แยกจากเคสลูกค้า

## ขั้นตอน

1. **ผู้ขอ** เปิดเว็บ login ด้วยบัญชี Microsoft ของบริษัท (ไม่มีบัญชี Microsoft 365: กด "รับลิงก์เข้าระบบทาง email" ใส่ email @sinostech.co.th แล้วกดลิงก์ใน email ใช้ได้ 15 นาที ครั้งเดียว ขอได้ 3 ครั้ง/ชั่วโมง บัญชีแบบนี้เป็นได้แค่ผู้ขอบริการ) ครั้งแรกระบบสร้างบัญชีบทบาท "ผู้ขอบริการ" ให้เอง (ไม่ต้องให้ Admin เพิ่ม) และขอให้ยืนยันหน่วยงาน ตำแหน่ง เบอร์โทร (ดึงจาก Microsoft มาให้ก่อนถ้ามี)
2. ผู้ขอกรอกทีม หัวข้อ รายละเอียด Severity วันที่ต้องการ (ตั้งแต่วันทำการถัดไป) แนบไฟล์ได้
3. ระบบ email ถึงผู้ขอ "ได้รับคำขอแล้ว รอ Manager อนุมัติ"
4. ระบบ email + Telegram ถึง **Manager ทุกคนของทีมนั้น** (ไม่มี Manager ในทีม = Admin) คนใดคนหนึ่ง
   - อนุมัติ: ตั้ง Target date (ต่างจากที่ขอต้องใส่เหตุผล), เลือกผู้รับผิดชอบ, ประเภทงาน → email ถึงผู้รับผิดชอบและผู้ขอ
   - ขอข้อมูลเพิ่ม → ผู้ขอแก้แล้วส่งใหม่
   - ไม่อนุมัติพร้อมเหตุผล
5. แจ้งเตือน (วันทำการ 08:30, email + Telegram):
   - ค้างอนุมัติเกิน 1 วันทำการ → Manager ทุกวันทำการ
   - 1 วันทำการก่อน Target → ผู้รับผิดชอบ + Manager
   - วันที่ครบ Target → ผู้รับผิดชอบ
   - เลย Target → ผู้รับผิดชอบ + Manager ทุกวันทำการ
6. ผู้รับผิดชอบ (หรือ Manager) ปิดคำขอ เลือกผลลัพธ์ ใส่เหตุผลอย่างน้อย 20 ตัวอักษร แนบไฟล์ส่งมอบได้ → email ถึงผู้ขอ

เพิ่มเติม: ผู้ขอแก้ไข/ยกเลิกได้ก่อนอนุมัติ, ทุกคนเพิ่มข้อมูลและไฟล์ได้ระหว่างทำ, ผู้รับผิดชอบขอเลื่อน Target ได้ (Manager อนุมัติ), ผู้ขอกด "ขอเปิดใหม่" ได้ภายใน 7 วันหลังปิด

## สิทธิ์

| | ผู้ขอบริการ | Engineer | Manager | Admin |
| --- | --- | --- | --- | --- |
| ส่งคำขอ | ✓ | ✓ | ✓ | ✓ |
| ดูคำขอ | ของตัวเอง | ที่ขอ / ได้รับมอบหมาย | ของทีมตัวเอง | ทั้งหมด |
| อนุมัติ / มอบหมาย / เลื่อน Target | | | ✓ | ✓ |
| ปิดคำขอ | | ที่ได้รับมอบหมาย | ✓ | ✓ |
| เห็นเคสลูกค้า KPI รายงาน | ไม่เห็น | ตามเดิม | ตามเดิม | ตามเดิม |

## KPI

คำขอที่ปิดแบบ "ส่งงานแล้ว" นับในหัวข้อ 5 ความหลากหลาย/ทักษะ ของผู้รับผิดชอบเท่านั้น (เพิ่มประเภทงาน และนับเป็นทักษะใหม่ถ้าเคยไม่ทำประเภทนั้น) ไม่มีคะแนนแยกหรือคะแนนโบนัส

## ตั้งค่า

- วันหยุดบริษัท: ตั้งค่า → วันหยุดบริษัท (เสาร์-อาทิตย์นับเป็นวันหยุดอยู่แล้ว)
- โดเมนที่ login เป็นผู้ขอบริการได้: `.env` → `REQUESTER_DOMAINS=sinostech.co.th` (ค่าเริ่มต้น)
- ปิดการแจ้งเตือนอัตโนมัติ: `V3_SR=0`
- การดึงหน่วยงาน/ตำแหน่ง/เบอร์จาก Microsoft ใช้สิทธิ์ `User.Read` แบบ delegated (อ่านเฉพาะข้อมูลของคนที่ login) ถ้าไม่ได้ ผู้ใช้กรอกเอง
